## 教學型 HTML 簡報

簡報以 [Wiki 知識庫] 為內容依據，依確認後的 [逐頁文案] 組裝，共 23 頁，包含獨立封面、封底、行星順序、距離、自轉公轉、分類、八大行星、環境比較、理解檢核及重點回顧。保留完整解說與粗體重點，封底前的「參考資料」頁只顯示「資料來源：NASA Science（ https://science.nasa.gov/ ）」。詳細檔案與頁碼引用保留於 Wiki。

- 點選「上一頁」「下一頁」，或使用鍵盤左右鍵切換。
- 上方選單可直接跳頁，Home 與 End 可到首頁及末頁。
- 理解檢核頁可展開參考答案與理由；瀏覽器支援時可使用全螢幕按鈕。
- 較長的頁面可在內容區垂直捲動；比較表可橫向捲動，底部切頁按鈕持續可用。列印樣式包含全部頁面。

## 本地檢查

修改 `copy.md` 後，執行 `node build.cjs` 重新產生 HTML，不需安裝套件。建置程式只轉換已確認的文案，不新增知識。

`node --check app.js` 檢查 JavaScript 語法。`node check.cjs` 核對 HTML 與文案同步、正文文字保留、來源集中封底前一頁、本地連結及簡化 DOM 下的切頁邏輯。此檢查不等同實際瀏覽器驗證。
